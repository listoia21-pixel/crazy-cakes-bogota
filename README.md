# Crazy Cakes Bogotá

Página web estática de pastelería y repostería personalizada en Bogotá.

Incluye un portafolio de 67 creaciones con siete categorías, fotos ampliables, animaciones y un formulario que prepara la cotización por WhatsApp.

## Publicación

GitHub Pages desde la rama `main`, carpeta raíz `/`.

No requiere instalación ni compilación. Para revisar localmente, sirve esta carpeta con un servidor HTTP y abre `index.html`.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css` y `motion.css`: diseño, adaptación móvil y movimiento reducido.
- `app.js` y `motion.js`: galería, cotización e interacciones.
- `gallery-data.js`: catálogo del portafolio.
- `assets/`: logo y fotografías optimizadas.
- `portfolio-sources.json`: procedencia de las fotos en Instagram.
